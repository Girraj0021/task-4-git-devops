# Git Documentation

## Git
Git is a distributed version control system used to track changes in source code.

## Git Workflow
The workflow used in this project is:

Feature Branch → Dev → Main

## Pull Request
A Pull Request is used to review and merge changes from one branch into another.

## Git Merge
Merge combines changes from different branches.

## Git Rebase
Rebase moves or reapplies commits on top of another branch.

## Git Stash
Git stash temporarily saves uncommitted changes.

## Git Tags
Tags are used to mark specific versions or releases.

## Git Ignore
.gitignore prevents selected files from being tracked by Git.
